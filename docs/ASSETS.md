# Assets

`frontend/public/images/medical-team.png` is an original image generated for this project on 2026-10-17: six fictional Indian clinician portraits in a 3-column by 2-row contact sheet. Profiles explicitly label these as sample portraits. They are not photographs of real doctors and imply no credentials or endorsements. No external image host is needed.

Inter and Playfair Display are bundled locally via the `@fontsource` packages. Their OFL license files are copied into `docs/licenses/`. Lucide icons are provided by `lucide-react` under its ISC license, also included there. Dependencies retain their own licenses in their packages and lockfiles.
